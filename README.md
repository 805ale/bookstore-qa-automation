# 📚 Bookstore QA Automation

This project is a **full-stack CRUD demo app** for an online bookstore, built to practice **QA automation & API testing**.

## 🚀 What’s inside
- **Backend** → Express + MongoDB (server/)
- **Frontend** → React + Vite (client/)
- **UI Tests** → Playwright (frontend/)
- **API Tests** → Postman (postman/)

## ⚙️ Getting Started

### Prerequisites
- Node.js 18+
- MongoDB (local `mongod` or Atlas connection string)
- Postman Desktop App
- Browsers (Playwright auto-installs)

### Setup

Backend:
```bash
cd server
npm install
npm run start
# -> http://localhost:2000
